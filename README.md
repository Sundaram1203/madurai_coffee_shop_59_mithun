# ☕ Naattu Suvai — Coffee Shop Website

A modern, responsive and visually engaging coffee shop website built using **HTML5, CSS3 and JavaScript**. The website presents the brand, menu, services, reservations, partnership information and contact details through a clean South Indian coffee-inspired design.

## 🌐 Live Demo

Live Website: https://naattu-suvai.vercel.app

---

## 📌 Project Overview

**Naattu Suvai** is a responsive coffee shop website designed to provide customers with an attractive online experience for discovering the coffee shop, exploring its menu, learning about its story and services, making table reservations, and getting in touch with the business.

The project focuses on:

* Responsive website design
* Clean and modern UI
* Coffee shop menu presentation
* Online table reservation interface
* Service and business information
* Contact page
* Interactive UI components
* Mobile-friendly navigation
* Image-based visual presentation

## 🗄️ Database

This project **does not use a database**.

It is a **frontend/static website**, so there is no:

* MySQL
* MongoDB
* PostgreSQL
* Firebase
* Backend API
* Node.js server
* Database authentication

The reservation and contact sections are currently frontend interfaces and require a backend/API integration if submitted data needs to be stored or processed.

## 🚀 Running the Project Locally

Since this is a static website, no Node.js installation or package manager is required.

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project

```bash
cd madurai_coffee_shop_59_mithun-main
```

### 3. Open the website

Open:

```text
index.html
```

directly in a browser.

Alternatively, use **VS Code Live Server** for a better development experience.
